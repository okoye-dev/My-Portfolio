ROADMAP FOR THE NEW PORTFOLIO

How to read this file: [x] means done, [ ] means not done yet. Items are in the order I suggest doing them. Edit freely.

The goal
A personal brand site for a product-minded software and AI engineer. It should feel calm, rounded and flowing like apple.com, with the confident type of unseen.co and the quiet restraint of fiasco.design. It must not look like it was made by an AI tool.

Where to find things
The new site lives at the normal routes: / , /projects , /blog , /personal.
The previous design is kept at /v1 so it can be opened any time. Its code is in app/v1 and the old components folder files (Hero, Navbar and so on).
Design rules, colours and references are in DESIGN.txt.
